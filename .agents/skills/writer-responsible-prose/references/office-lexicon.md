# Office leftovers and cleft templates

Swap on sight; replace rather than tone down.

## Indian-office phrasing

| Don't | Do |
|---|---|
| kindly | please, or just the verb |
| revert / revert back | reply, get back to me |
| do the needful | name the action and the deadline |
| the same | repeat the noun |
| prepone | move up, reschedule earlier |
| out of station | out of town, traveling |
| I have a doubt | I have a question |
| intimate (for inform) | tell, let me know |
| pass out of college | graduate |
| good name | name |
| humble request | please |
| for your kind perusal / kind information / kind action | FYI, or state the ask |
| aforesaid / hereby / concerned person | the report / I / Priya |
| Respected Sir/Madam | Hi Name, or no greeting |
| Thanking you | Thanks |
| at the earliest | by Tuesday, ASAP |
| discuss about | discuss |
| updation / upgradation | update / upgrade |
| as per | according to, under |
| in this regard | drop it |

## Cleft and caption templates

| Don't | Do |
|---|---|
| That is what X | X, or *which means X* |
| This is how X | so X / which X |
| X is what lets Y | X lets Y / Y happens when X |
| X is how Y | X, so Y / X, which Y |
| X is where Y shows up | Y shows up in X |
| The key is X | X |
| The real value is X | Buyers pay for X / You get X |
| What this means is X | X |
| This means that X | so X |

## Grammar leftovers that travel with the cadence

- Stative progressive: *I am knowing / I am understanding / I am having two GPUs* → *I know / I understand / I have two GPUs*
- Invariant tag: *…isn't it?* on every sentence → drop, or match the auxiliary
- Focus *only* / *itself* at the end: *I am here only* / *today itself* → *just* / *right* / *exactly*, or cut
- Mass nouns pluralized: *equipments, furnitures, feedbacks* → *equipment, furniture, feedback*
- Extra particles: *return back, revert back, discuss about, repeat again* → drop the extra word

## Spelling when the audience is American

colour → color, centre → center, organise → organize, defence → defense, travelling → traveling, learnt → learned, maths → math, holiday (time off) → vacation.
